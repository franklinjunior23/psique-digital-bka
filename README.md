# Psique Digital BKA

Página de inicio de **Psique Digital BKA**: psicología y bienestar emocional en línea.

Sitio estático (HTML, CSS y JavaScript, sin dependencias). Para verlo en local:

```sh
python3 -m http.server 4321
# abre http://localhost:4321
```

- `index.html`, `styles.css`, `main.js`: la página.
- `img/`: imágenes de la marca y fotos de Unsplash (licencia Unsplash).
- `fonts/`: fuentes autoalojadas (Google Fonts, licencia OFL).
- `PRODUCT.md` y `DESIGN.md`: contexto del producto y sistema de diseño.
